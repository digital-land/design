A [waste plan][term:waste-plan] sets out policies for how waste will be managed in an area.

Each [waste plan][term:waste-plan] that a minerals and waste planning authority is responsible for. There is a separate row for each current, emerging or historical [waste plan][term:waste-plan].

Use this to:

* check whether a plan is still in date
* find out which authority or group of authorities are responsible for the waste plan
* link to detailed information on the plan
